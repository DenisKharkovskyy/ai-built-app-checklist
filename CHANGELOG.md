# Changelog

Versions are dates (`Version: YYYY-MM-DD`), the same as on [selfoia.com/checklist](https://selfoia.com/checklist). Each version is a GitHub release tagged `vYYYY-MM-DD`.

## 2026-09-27

First public version.

- 24 checks, E01–E24, in five zones: Leaks, Break-ins, Money, Speed and Safety net.
- `CHECKLIST.md`: the checklist for AI coding agents, the same text as [selfoia.com/checklist.md](https://selfoia.com/checklist.md).
- `SELF-TEST.md`: the human version, with a 2-minute self-test per check, the same content as [selfoia.com/checklist](https://selfoia.com/checklist).
- `PROMPT.md`: the copy-paste prompts for Cursor, Claude Code and other AI coding tools.
